## 🏛️ End-to-End System Topology

> *Live architecture blueprint illustrating how my frontend, backend, database, and AI layers interact in production:*

```mermaid
graph LR
    subgraph Client ["💻 Client Layer (Next.js / React)"]
        UI["Tailwind UI + Zustand + i18next"]
        RTC["WebRTC Media & Socket.io Client"]
    end

    subgraph Gateway ["🛡️ API & Real-Time Gateway (NestJS / Express)"]
        Auth["Passport.js • OAuth2 • JWT • OTP"]
        API["REST Controllers & Stripe Webhooks"]
        WS["Socket.io Signaling Server"]
    end

    subgraph AI ["🧠 Agentic AI Engine (LangGraph)"]
        Orchestrator["Stateful Agent Router"]
        Tools["Tavily Search • OS Function Calling"]
    end

    subgraph Data ["🗄️ Persistence & Cloud Storage"]
        SQL[("PostgreSQL (Prisma / TypeORM)")]
        NoSQL[("MongoDB (Mongoose)")]
        Vector[("Pinecone Vector Index")]
        CDN["Cloudinary Media Pipeline"]
    end

    UI ==> Auth
    Auth ==> API
    RTC <==> WS
    API ==> Orchestrator
    Orchestrator <==> Tools
    Orchestrator <==> Vector
    API ==> SQL
    API ==> NoSQL
    API ==> CDN
```
